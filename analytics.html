Events this site will track in GA4

Once a real GA4 Measurement ID is inserted into site-config.js, every page will send normal page-view data. Referral buttons also send a custom referral_click event with the company name, destination URL, link text, and page path.

After GA4 is connected

  1. Use Realtime to confirm your own visit appears.
  2. In Reports/Explorations, filter event name to referral_click.
  3. Use the event parameter company to compare outbound sign-up interest by panel.
  4. Use Search Console separately to see which Google queries generate impressions and clicks.
